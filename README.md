# Shaik Luqman — Portfolio

Personal portfolio of **Shaik Luqman** — full-stack engineer building applied-AI systems, secure infrastructure, and real products. Light, Apple-inspired single-page site — floating product cards, bento grids, and scroll-driven motion with a warm amber accent.

## Stack

- [Vite](https://vitejs.dev/) + [React 18](https://react.dev/) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/) (via `@tailwindcss/vite` — design tokens live in `src/index.css` under `@theme`)
- [Motion](https://motion.dev/) (framer-motion) for all animation, with full `prefers-reduced-motion` support
- [lucide-react](https://lucide.dev/) icons
- Self-hosted fonts via `@fontsource/inter` and `@fontsource/jetbrains-mono` — no font CDN
- Fully static, no backend

## Local development

Requires Node.js 20+. On Apple Silicon, use a native (arm64) Node — e.g.
`brew install node` with Homebrew in `/opt/homebrew`.

```bash
npm install
npm run dev        # start dev server at http://localhost:5173
```

Other scripts:

```bash
npm run build      # type-check, build, then prerender every route into dist/
npm run preview    # serve the production build locally
```

### How the build makes the site crawlable

`npm run build` runs four steps:

1. `tsc` — type-check.
2. `vite build` — the browser bundle (site code, `react`, and `motion` are split into separate chunks so library code stays cached across deploys).
3. `vite build --ssr src/entry-server.tsx` — a server build of the same app.
4. `node scripts/prerender.mjs` — renders `/`, `/projects/metroflow`, and `/projects/suraksha` to static HTML with per-page `<title>`, description, canonical URL, Open Graph/Twitter cards and JSON-LD (all defined in `src/lib/seo.ts`), preloads the critical fonts, and writes `sitemap.xml` and `404.html`.

Crawlers and link-preview bots (LinkedIn, WhatsApp, Slack, X), which don't run JavaScript, therefore see the real content and the right preview card. In the browser the app boots normally and takes over.

### Share images

`public/og.png` and `public/og-<slug>.png` are generated by `node scripts/og-images.mjs` (macOS only; run it after `npm run build`, then commit the PNGs). After deploying, refresh LinkedIn's cache with the [Post Inspector](https://www.linkedin.com/post-inspector/).

## Deploying to Vercel

Zero configuration needed — Vercel auto-detects Vite.

**Option A — Git integration (recommended):**

1. Push this repo to GitHub.
2. On [vercel.com](https://vercel.com), click **Add New → Project** and import the repo.
3. Vercel detects the Vite preset (build: `npm run build`, output: `dist`). Click **Deploy**.

**Option B — CLI:**

```bash
npx vercel         # preview deploy
npx vercel --prod  # production deploy
```

## ⚠️ Before you ship

- **Keep `public/resume.pdf` current** — every Résumé button points to `/resume.pdf` (desktop opens it in an inline viewer; phones open the PDF directly).
- **Drop in real repo links** — search for `TODO` in `src/components/Projects.tsx`; both project cards currently point at the GitHub profile as a placeholder.

## Design tokens

Everything is themed through CSS variables in `src/index.css`:

| Token | Value | Use |
| --- | --- | --- |
| `paper` | `#F6F5F2` | warm off-white page background |
| `card` | `#FFFFFF` | floating cards / tiles |
| `ink` | `#1B1B1E` | primary text |
| `mute` | `#52525B` | secondary text |
| `dim` | `#6E6E76` | captions, mono labels |
| `line` | `#E6E4DD` | hairline borders |
| `noir` | `#101013` | dark contrast cards (AI tile, Suraksha, contact) |
| `brand` | `#F5A623` | bright amber — fills, buttons, graphics |
| `accent` | `#B45309` | deep amber — text-safe links and labels |

Type: **Inter** for UI and headings, **JetBrains Mono** for section numbers, tech tags, and technical labels.
